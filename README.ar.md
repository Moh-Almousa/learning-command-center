# مركز قيادة التعلّم — Learning Command Center

تطبيق ويب شخصي لتخطيط تعلّمك ومتابعته: خريطة تعلّم، تقدّم محسوب تلقائياً، سجلّ كامل لرحلتك، مشاريع، شهادات، وإحصائيات.
يعمل بالكامل داخل المتصفح: بدون Backend، وبدون قاعدة بيانات، وبدون تسجيل دخول. هو مجرد ملفات ثابتة تستضيفها على GitHub Pages.
الواجهة بلغتين: العربية والإنكليزية.

> 📘 **لتتعلّم كيف تستخدم الموقع خطوة بخطوة، اقرأ [دليل الاستخدام](GUIDE.ar.md).**
> English version: [README.md](README.md)

**الاستخدام اليومي يتم من الموقع نفسه:** تفتح، تضغط، تضيف، تكتب، ثم تحفظ.
لا تحتاج أن تعدّل أي كود لإضافة أو تغيير الكورسات والدروس والمهام والمشاريع والشهادات والمهارات والروابط والملاحظات.

## ماذا يفعل التطبيق؟

- **خريطة التعلّم (Roadmap):** خريطة تفاعلية تدعم Zoom وPan وPinch وFit، وفيها توسيع وطيّ للعناصر، وأسهم للمتطلبات السابقة، وحالة Locked. وهناك عرض شجرة (Outline) للموبايل.
- **هرمية لكل مستوى فيها تقدّمه الخاص:** مسار تعلّم ← محور ← كورس ← وحدة ← درس ← مهمة.
  عندما تُنهي مهمة، يُعاد الحساب فوراً للدرس ثم الوحدة ثم الكورس ثم المحور ثم المسار ثم التقدّم الكلي.
- **سجلّ لا يُمحى أبداً:**
  - كل تغيّر في النسبة يُحفظ مع تاريخه، ويظهر كرسم بياني وجدول في صفحة كل عنصر.
  - كل حدث (بدء، إكمال، إعادة فتح) يُحفظ مع أثره، مثلاً "Django من 68% إلى 72%".
  - الكورس المكتمل لا يُحذف، ويبقى بكل دروسه وتواريخه وملاحظاته ومصادره.
  - يمكنك **إعادة فتح** أي شيء أنهيته، إما للمراجعة أو للبدء من جديد، ويبقى تاريخ الإكمال الأول محفوظاً.
- **صفحة لكل عنصر** على الرابط `#/learn/<id>`، وتعرض:
  - أين وصلت داخله.
  - "ماذا أنجزت؟": المكتمل، وقيد التنفيذ، والمتبقي.
  - المحتويات، وسجلّ التقدّم، وسجلّ الأحداث، وسجلّ مرات الإكمال.
- **لوحة التحكم:**
  - "أين أنت": من التقدّم الكلي حتى المهمة الحالية.
  - زر "تابع التعلّم".
  - "تعلّم اليوم" والخطوة التالية المقترحة.
  - الكورسات المكتملة والمشاريع النشطة.
- **الشهادات:**
  - معرض شهادات مرتبط بالكورسات، مع صور مصغّرة تُحمَّل عند الحاجة فقط (lazy).
  - بحث وفلترة، ونافذة معاينة فيها View وOpen Original وEdit.
  - الشهادة اختيارية ولا تؤثر على إكمال الكورس.
- **المشاريع:**
  - عرض قائمة شطب وعرض Kanban.
  - مجموعات، وأولويات، واعتماديات بين المهام، ومراحل (Milestones).
  - "ما طبّقته"، وروابط التعلّم، وملاحظات، وخط زمني، وإحصائيات، وقوالب جاهزة.
- **تخصيص المحتوى:** صفحة واحدة تضيف منها أي شيء، وتعدّل وتنقل وترتّب خطة التعلّم كلها، وتدير المشاريع والمهارات والتقنيات والقوالب والقوائم.
- **القوائم:** قوائمك الخاصة، مثل قائمة قراءة أو تحضير مقابلات أو كتب أو مسائل تدريب.
- **النشاط وسجلّ التعلّم، والمراجعة الأسبوعية، والإحصائيات، والبحث، ووضع التركيز، والمؤقت.**
- **التصدير والاستيراد وإعادة الضبط.**
- **الإعدادات:**
  - **المظهر:** سمة داكنة أو فاتحة أو حسب النظام، ولون أساسي، وألوان مخصّصة، وكثافة العرض، والحركة.
  - **خيارات التعلّم والمشاريع:** الحالة الافتراضية، وطريقة حساب التقدّم، والعرض الافتراضي، وتجميع المهام.
  - **التخصيص الشخصي:** اسمك، وهدفك، وتركيز تثبّته، واللغة.

## كيف تُنظَّم البيانات (الحالة الحالية مقابل السجلّ)

كل بياناتك محفوظة في كائن واحد في `localStorage['lcc.state.v1']`، وهو نفسه الملف الذي تنزّله عند التصدير:

| الجزء | ما هو |
|---|---|
| `nodes` | بيانات عناصر التعلّم وحالتها الحالية: العنوان، والنوع، والأب، والأبناء، والحالة، والتواريخ، والملاحظات، والمصادر، والمتطلبات. ويشمل `completions`: كل مرة أُكمل فيها العنصر أو أُعيد فتحه |
| `progress` | النسبة والحالة المحسوبة حالياً لكل عنصر يحتوي عناصر، وتُستخدم لاكتشاف التغيّرات |
| `progressLog` | **سجلّ**: كل تغيّر في التقدّم بصيغة `{ ts, id, from, to, fromStatus, toStatus }`، ولا يُحذف منه شيء |
| `activity` | **سجلّ**: كل حدث (بدء، إكمال، إعادة فتح، جلسة، أحداث المشاريع والشهادات…) مع أثره `effects` |
| `projects` و`ptasks` | المشاريع ومهامها |
| `certificates` | بيانات الشهادات وروابطها فقط (انظر الفقرة التالية) |
| `skills` و`technologies` و`templates` و`lists` | المهارات، والتقنيات، والقوالب، والقوائم |
| `sessions` و`today` و`reviews` | جلسات الدراسة، وخطط الأيام، وملاحظات المراجعة الأسبوعية |
| `settings` | التفضيلات، والمظهر، واللغة |

- **النسب لا تُكتب يدوياً أبداً.** هي تُحسب دائماً من العناصر الموجودة داخل كل عنصر.
- **السجلّ لا يُحذف تلقائياً.** البيانات القديمة تُرحَّل لصيغة أحدث عند التحميل عبر `normalize()` في `store.js`، دون أن تضيع.

**الشهادات والتخزين:**
- **ما يُخزَّن:** الشهادة تُخزَّن كحقول قصيرة فقط: `title, provider, issueDate, expiryDate, credentialId, status, certificateUrl, imageUrl, thumbnailUrl, notes, nodeId`.
- **ما لا يُخزَّن:** لا تُخزَّن أبداً كصورة أو PDF بصيغة Base64، والروابط التي تبدأ بـ `data:` تُرفض.
- **الأداء:** بطاقات المعرض تحمّل الصورة المصغّرة فقط بـ `loading="lazy"`، والصورة الكاملة لا تُحمَّل إلا عند فتح المعاينة.
- **الرفع مستقبلاً:** كل مكان يحتاج ملفاً يستدعي `asset(cert, kind)` في `certificates.js`، ولكل شهادة حقل محجوز `file` بصيغة `{ storage, key, mime, size }`. لإضافة رفع ملفات إلى Backend لاحقاً، تملأ هذا الحقل وتعدّل `asset()` فقط.

## التشغيل على جهازك

افتح `index.html` في Chrome أو Edge أو Firefox، أو شغّل خادماً محلياً:

```bash
cd learning-command-center
python3 -m http.server 8000     # ثم افتح http://localhost:8000
```

> ⚠️ البيانات تُحفظ حسب العنوان. `file://…` و`localhost` ورابط GitHub Pages الخاص بك، لكل منها نسخة مستقلة.
> لنقل بياناتك بينها استخدم **البيانات ← تصدير البيانات / استيراد البيانات**.

## النشر على GitHub Pages

1. **أنشئ المستودع:** أنشئ مستودعاً باسم **`<username>.github.io`**، فيكون الموقع على `https://<username>.github.io`.
   أو أي اسم آخر، فيكون الموقع على `https://<username>.github.io/<repo>/`.
2. **ارفع الملفات:** ضع الملفات بحيث يكون `index.html` في جذر المستودع، ثم ارفعها:
   ```bash
   git init && git add . && git commit -m "Learning Command Center"
   git branch -M main
   git remote add origin https://github.com/<username>/<username>.github.io.git
   git push -u origin main
   ```
   أو من موقع GitHub: **Add file ← Upload files**.
3. **فعّل GitHub Pages:** افتح **Settings ← Pages ← Build and deployment**، واختر Source: **Deploy from a branch**، وBranch: **`main`** و**`/(root)`**، ثم **Save**.
4. **افتح الموقع:** انتظر دقيقة أو دقيقتين، ثم افتح الرابط الذي يظهر أعلى صفحة Pages.

**التحديث لاحقاً:** ارفع الملفات الجديدة فوق القديمة. تقدّمك محفوظ في متصفحك وليس في المستودع، لذلك لا يتأثر.

## التخصيص

| أريد أن… | أين |
|---|---|
| أضيف أو أعدّل أو أنقل أو أرتّب أي شيء | صفحة **تخصيص المحتوى**، أو زر ✎ الموجود في كل مكان |
| أغيّر الألوان والسمة والكثافة والحركة | **الإعدادات ← المظهر** |
| أغيّر ألوان التصميم من الكود | `css/variables.css`، وهو ملف واحد فقط |
| أغيّر المحتوى الذي يبدأ به أي تثبيت جديد | ملفات `data/*.js` |
| أغيّر نصوص الواجهة أو أضيف لغة | `js/i18n.js` و`js/i18n-ar.js` |

### إضافة ميزة جديدة (للمطوّر)

كل صفحة تسجّل نفسها، والشريط الجانبي يُبنى تلقائياً من الصفحات المسجّلة.
لذلك الصفحة الجديدة تحتاج ملفاً واحداً + وسم `<script>` واحداً في `index.html`:

```js
(function (App) {
  App.Pages.books = {
    render(el, params, sub) { el.innerHTML = '<h1>Books</h1>'; },
    title: () => App.i18n.t('nav.books'),
    nav: { icon: 'book', order: 75 },          // احذف nav إن لم ترد ظهورها في الشريط الجانبي
  };
})(window.App = window.App || {});
```

- **البيانات الجديدة:** ضعها تحت مفتاح جديد في `Store.emptyState()`، وأعطها قيمة افتراضية في `normalize()` حتى تبقى النسخ الاحتياطية القديمة قابلة للاستيراد.
- **بدون كود أصلاً:** كثير من أفكار "متابعة قائمة أشياء" (كتب، شهادات، تحضير مقابلات) لا تحتاج كوداً. استخدم **القوائم**.

## اللغات

- **التبديل:** بدّل اللغة بزر **ع / EN** في الشريط العلوي، أو من **الإعدادات ← اللغة**.
- **الاتجاه:** العربية تقلب الواجهة كلها من اليمين لليسار، بما فيها خريطة التعلّم.
- **محتواك:** أسماء الكورسات والملاحظات وغيرها تبقى كما كتبتها، ولا تُترجم.
